# ATM Simulation

## Overview

ATM Simulation is a C programming project that mimics basic ATM operations. The system allows users to authenticate using a PIN and perform banking transactions through a menu-driven interface.

## Features

* PIN Authentication
* Balance Inquiry
* Money Deposit
* Money Withdrawal
* Menu-Driven Interface
* Input Validation

## Technologies Used

* C Programming Language
* OnlineGDB

## How It Works

1. User enters the ATM PIN.
2. After successful authentication, the ATM menu is displayed.
3. The user can:

   * Check account balance
   * Deposit money
   * Withdraw money
   * Exit the application
4. The account balance is updated after each transaction.
